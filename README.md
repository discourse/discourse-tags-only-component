# Tags Only

**Theme Summary**

This is a CSS-only component meant to make it easier to create a tag-focused Discourse site without categories.

One category must be used, but can be hidden. Be sure to set the site setting `Default composer category` to the default category of your choice.

Categories are still listed and accessible from /categories, which can be utilized by admins to access category settings if needed. The `/categories` link for regular users can be hidden by removing it from the site setting `top_menu`.
